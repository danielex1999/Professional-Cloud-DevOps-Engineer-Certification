# Firestore

## ¿Qué es?

Firestore es una base de datos **NoSQL**, flexible y escalable horizontalmente.

Está orientada principalmente a aplicaciones:

- Móviles
- Web
- Servidores

## ¿Cómo almacena los datos?

La estructura es:

**Colecciones → Documentos → Campos (clave-valor)**

Ejemplo:

```text
usuarios
 └── usuario123
      ├── nombre: Juan
      └── apellido: Cavero
