# Cloud Spanner

## ¿Qué es?

Spanner es un servicio administrado de **bases de datos relacionales** de Google Cloud.

Utiliza **SQL** y puede escalar **horizontalmente**.

## Características principales

- Base de datos relacional
- SQL
- Escalado horizontal
- Alta disponibilidad
- Coherencia fuerte
- Coherencia global
- Índices secundarios
- Joins
- Alto rendimiento de lectura y escritura

## ¿Cuándo usar Spanner?

Es ideal cuando necesitas:

**Base de datos relacional + SQL + escala global + alta disponibilidad + muchas operaciones por segundo.**

Puede manejar **decenas de miles de operaciones de lectura y escritura por segundo o más**.

## Spanner vs Cloud SQL

**Cloud SQL**
→ Base de datos relacional administrada para cargas tradicionales.

**Spanner**
→ Base de datos relacional administrada cuando necesitas **escalabilidad horizontal y consistencia global**.

## Para examen

Si aparece:

**SQL + relacional + escalabilidad horizontal + consistencia global + alta disponibilidad**

→ **Cloud Spanner**
