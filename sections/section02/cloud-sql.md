# Cloud SQL

## ¿Qué es?

Cloud SQL es un servicio de **bases de datos relacionales administradas** de Google Cloud.

Soporta:

- MySQL
- PostgreSQL
- SQL Server

## ¿Qué administra Google?

Google se encarga de tareas como:

- Parches y actualizaciones
- Copias de seguridad
- Replicación
- Encriptación
- Infraestructura

Así, el desarrollador se concentra en la aplicación.

## Características

- Escalabilidad de CPU, RAM y almacenamiento
- Réplicas automáticas
- Backups administrados
- Recuperación de datos
- Firewall de red
- Encriptación de datos
- Acceso desde otros servicios de Google Cloud
- Acceso desde aplicaciones externas

## Integración

Cloud SQL puede trabajar con:

**App Engine → Cloud SQL**

**Compute Engine → Cloud SQL**

También puede utilizar herramientas externas como:

- SQL Workbench
- Toad
- MySQL Workbench y otros clientes compatibles

## Concepto clave

**Cloud SQL = Base de datos relacional administrada**

Google administra la infraestructura y tareas operativas como backups, parches y replicación.

## Para examen

Si la pregunta habla de:

**MySQL / PostgreSQL / SQL Server + base de datos relacional + servicio administrado**

→ **Cloud SQL**
