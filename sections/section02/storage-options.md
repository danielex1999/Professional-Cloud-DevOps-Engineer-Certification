# Servicios de Almacenamiento en Google Cloud

Todas las aplicaciones necesitan **almacenar datos**, como contenido multimedia o datos provenientes de sensores.

Dependiendo de la aplicación y del tipo de datos, se pueden utilizar diferentes soluciones de almacenamiento.

## Productos de almacenamiento

Google Cloud cuenta con **5 productos principales**:

```text id="h6q3mz"
Google Cloud Storage
       │
       ├── Cloud Storage
       ├── Cloud SQL
       ├── Spanner
       ├── Firestore
       └── Bigtable
```

Estos servicios permiten trabajar con diferentes tipos de datos y cargas de trabajo:

* Datos estructurados.
* Datos no estructurados.
* Datos transaccionales.
* Datos relacionales.

### ¿Cuál utilizar?

Una aplicación puede utilizar **uno o varios** de estos servicios dependiendo de sus necesidades.

```text id="p9k4vx"
Aplicación
    │
    ├── Servicio de almacenamiento A
    ├── Servicio de almacenamiento B
    └── Servicio de almacenamiento C
```
