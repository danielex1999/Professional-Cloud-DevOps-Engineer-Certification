# Interoperabilidad y Código Abierto

Algunas empresas temen llevar sus cargas de trabajo a la nube porque creen que tendrán que comprometerse para siempre con un solo proveedor.

Google plantea la posibilidad de ejecutar las aplicaciones en otro lugar si el cliente decide utilizar otro proveedor.

## Código abierto

Google publica elementos tecnológicos clave con **licencias de código abierto** para crear ecosistemas donde los clientes puedan elegir otras opciones además de Google.

### TensorFlow

**TensorFlow** es una biblioteca de software de código abierto para el **aprendizaje automático (AA)** desarrollada dentro de Google.

Es el núcleo de un ecosistema de código abierto.

## Interoperabilidad

Google proporciona interoperabilidad en varias capas de la pila.

| Tecnología                         | Función                                                                          |
| ---------------------------------- | -------------------------------------------------------------------------------- |
| **Kubernetes**                     | Permite combinar microservicios que se ejecutan en distintas nubes.              |
| **Google Kubernetes Engine (GKE)** | Permite trabajar con microservicios que se ejecutan en distintas nubes.          |
| **Google Cloud Observability**     | Permite supervisar cargas de trabajo de varios proveedores de servicios de nube. |

```text
Código abierto
      ↓
Interoperabilidad
      ↓
Múltiples nubes
      ↓
Mayor posibilidad de elegir proveedores
```
