# Bigtable

## ¿Qué es?

Bigtable es el servicio de base de datos **NoSQL para Big Data** de Google Cloud.

Está diseñado para manejar grandes cantidades de datos con:

- Baja latencia
- Alto rendimiento
- Alta capacidad de procesamiento

## ¿Cuándo usar Bigtable?

Es especialmente útil cuando:

- Tienes **más de 1 TB** de datos
- Los datos son estructurados o semiestructurados
- Los datos cambian rápidamente
- Necesitas alto throughput
- Trabajas con datos NoSQL
- Tienes datos de series temporales
- Necesitas procesamiento en tiempo real o por lotes
- Utilizas Machine Learning sobre los datos

## Casos de uso

- IoT
- Análisis de usuarios
- Datos financieros
- Series temporales
- Big Data
- Machine Learning

## Procesamiento

Bigtable puede integrarse con:

- Dataflow
- Spark
- Hadoop MapReduce
- Spark Streaming
- Storm

También permite leer y escribir datos mediante APIs y clientes compatibles con HBase.

## Concepto clave

**Bigtable = NoSQL + Big Data + alto rendimiento + baja latencia**
